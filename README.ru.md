## <img src="https://github.com/KrishBharadwaj5678/divya-darshan/raw/main/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Скачайте изображения

- **Скачайте изображения** из папки `markers` репозитория на своё устройство.

### 2️⃣ Скачайте приложение

- [Скачайте приложение](https://drive.google.com/file/d/1CLGP1bK2tnEt4zZ9KtyMmMPWp12zXMqN/view?usp=sharing), используя ссылку, предоставленную в репозитории.

### 3️⃣ Запустите приложение

- **Откройте приложение**, чтобы начать погружение в дополненную реальность.

### 4️⃣ Отсканируйте изображение

- **Отсканируйте любое скачанное изображение** с помощью приложения, чтобы активировать AR-взаимодействие.

### 5️⃣ Наслаждайтесь дополненной реальностью

- **Просматривайте божество в захватывающем 3D-формате** и взаимодействуйте с ним посредством дополненной реальности.
