## <img src="https://github.com/KrishBharadwaj5678/divya-darshan/raw/main/readme/gifs/howItWorks.gif" width="35"/> Как это работает

### 1️⃣ Скачайте изображения

- **Скачайте изображения** из папки `markers` в репозитории на своё устройство.

### 2️⃣ Скачайте приложение

- [Скачать приложение](https://drive.google.com/file/d/1CLGP1bK2tnEt4zZ9KtyMmMPWp12zXMqN/view?usp=sharing) можно по ссылке, указанной в репозитории.

### 3️⃣ Запустите приложение

- **Откройте приложение**, чтобы начать погружение в дополненную реальность.

### 4️⃣ Отсканируйте изображение

- **Отсканируйте любое скачанное изображение** с помощью приложения, чтобы активировать AR-эффект.

### 5️⃣ Насладитесь дополненной реальностью

- Увидьте божество в реалистичном 3D-формате
