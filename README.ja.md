## <img src="https://github.com/KrishBharadwaj5678/divya-darshan/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ 画像をダウンロード

- リポジトリ内の `markers` フォルダから**画像をダウンロード**して、お使いのデバイスに保存してください。

### 2️⃣ アプリをダウンロード

- リポジトリに記載されているリンクから[アプリをダウンロード](https://drive.google.com/file/d/1CLGP1bK2tnEt4zZ9KtyMmMPWp12zXMqN/view?usp=sharing)してください。

### 3️⃣ アプリを起動

- **アプリを開いて**、没入感のある拡張現実体験を始めましょう。

### 4️⃣ 画像をスキャン

- アプリを使って**ダウンロードした画像のいずれかをスキャン**すると、AR体験が起動します。

### 5️⃣ ARで体験

- **神々を臨場感あふれる3Dで表示**し、拡張現実を通じて体験することができます。
