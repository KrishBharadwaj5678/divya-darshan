## <img src="https://github.com/KrishBharadwaj5678/divya-darshan/raw/main/readme/gifs/howItWorks.gif" width="35"/> 使用方法

### 1️⃣ 画像をダウンロードする

- リポジトリ内の `markers` フォルダから画像をダウンロードし、デバイスに保存します。

### 2️⃣ アプリをダウンロードする

- [こちらからアプリをダウンロード](https://drive.google.com/file/d/1CLGP1bK2tnEt4zZ9KtyMmMPWp12zXMqN/view?usp=sharing)してください。

### 3️⃣ アプリを起動する

- アプリを開いて、没入感のある拡張現実（AR）体験を始めましょう。

### 4️⃣ 画像をスキャンする

- ダウンロードした画像のいずれかをアプリでスキャンすると、AR体験が開始されます。

### 5️⃣ AR体験を楽しむ

- 神々の立体的な3Dモデルを表示し、拡張現実を通じて神聖な体験をお楽しみください。
